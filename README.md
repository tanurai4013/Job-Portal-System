# Job Portal System

A backend Job Portal application built using **Java and Spring Boot** that allows recruiters to post jobs and candidates to search and apply for jobs.
The system provides secure authentication using **JWT** and follows REST API architecture.

---

##  Features

* User Registration and Login
* Secure Authentication using JWT
* Role-based access (Recruiter / Job Seeker)
* Recruiters can post and manage jobs
* Candidates can search and apply for jobs
* RESTful API design
* Database integration with MySQL

## ⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/tanurai4013/Job-Portal-System.git

2. Navigate to the project directory

cd Job-Portal-System

3. Configure MySQL database in **application.properties**

4. Run the Spring Boot application

## 📌 API Testing
